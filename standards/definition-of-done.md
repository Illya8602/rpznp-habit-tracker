# Власний Definition of Done (DoD)

Робота вважається завершеною за таких умов:

1. **Типізація**: TypeScript компілюється без помилок (`npm run typecheck`).
2. **Статичний аналіз**: ESLint та Prettier проходять без помилок чи попереджень.
3. **Smoke-тести**: Проходять успішно як локально, так і в конвеєрі (`npm run test:smoke`).
4. **Ізоляція шарів**: Транспорт (HTTP) не знає про сховище (БД); репозиторій ізольований від HTTP.
5. **Гігієна Git**: Відсутні сторонні файли (.env, кеші, node_modules), коміти слідують Conventional Commits.
6. **Артефакти здачі**: Створено та оновлено DEFENSE.md і супутні ADR.
