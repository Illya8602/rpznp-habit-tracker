# 0001. Вибір Fastify як HTTP-рушія замість Express

- Статус: accepted
- Дата: 2026-10-10

## Контекст і постановка проблеми

Для проєкту Habit Tracker API необхідно обрати HTTP-фреймворк на платформі Node.js.

## Фактори прийняття рішень

- Вбудована валідація схем.
- Висока пропускна здатність.
- Архітектура плагінів.

## Розглянуті варіанти

- **Express.js**: Класичний, але повільний інструмент із застарілими middleware.
- **Fastify**: Швидкий роутер із нативною підтримкою JSON Schema.

## Результат рішення

Обрано **Fastify**.

### Наслідки

- Позитивні: Швидка серіалізація JSON, готовність до навантажувальних тестів, проста мок-ізоляція.
- Негативні / компроміси: Потребує вивчення екосистеми плагінів Fastify замість звичних Express middleware.
