# 0002. Вибір Vitest та автоматичного конвеєра збірки

- Статус: accepted
- Дата: 2026-10-11

## Контекст і постановка проблеми

Необхідно забезпечити відтворювану перевірку якості коду та швидкодію smoke-тестів.

## Фактори прийняття рішень

- Швидкість виконання тестів.
- Інтеграція з TypeScript без окремого кроку транспіляції для тестів.

## Розглянуті варіанти

- **node:test**: Вбудований модуль Node.js, але вимагає додаткового налаштування лоадерів для TypeScript.
- **Vitest**: Сучасний тестовий ранер із миттєвим запуском TS-тестів.

## Результат рішення

Обрано **Vitest**.
